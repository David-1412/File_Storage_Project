Storage & File Sharing Platform
A modern, full-stack storage management solution that allows users to upload, organize, and share files seamlessly. This platform provides a personalized dashboard to track storage usage and a robust interface for managing various file types including documents, images, and media.

⚙️ Tech Stack
Framework: Next.js 15 (App Router)

Library: React 19

Backend-as-a-Service: Appwrite (Authentication, Database, and Storage)

Styling: Tailwind CSS

UI Components: Shadcn UI

Language: TypeScript

🔋 Features
User Authentication: Secure signup, login, and logout functionality using Appwrite’s Auth system with OTP verification.

File Uploads: Supports multiple file formats (PDF, images, video, audio) with real-time upload tracking.

File Management: Full CRUD capabilities allowing users to rename, delete, and download files directly from the interface.

File Sharing: Collaborative features to share specific files with other users via email.

Dynamic Dashboard: A comprehensive overview of total storage consumed, recent activity, and files categorized by type.

Global Search & Filtering: Fast search functionality to locate files and advanced sorting by name, size, or date created.

Responsive Design: Fully optimized for mobile, tablet, and desktop views with a clean, minimalist UI.
